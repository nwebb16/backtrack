# Backtrack

Personal daily diary for tracking L5/S1 back pain, rehab progress, and pain
triggers. Single-file static HTML app (no build step), backed by Supabase
(Postgres) for storage — same pattern as the NKW Pipeline and Progress
Meetings apps. Strava activities sync in automatically via a scheduled task.

Open `index.html` directly, or via the published GitHub Pages URL on your
phone (Safari → Share → Add to Home Screen) for a proper app icon.
